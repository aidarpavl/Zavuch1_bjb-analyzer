# 📊 Талдау көмекшісі — помощник учителя

Веб-приложение на Streamlit для анализа школьных Excel-отчётов:
- **анализ БЖБ (СОР) и ТЖБ (СОЧ)** по классу;
- **успеваемость школы по параллелям** за четверть (оқу озаты, екпінділер, білім сапасы, орташа балл, резерв).

Тип отчёта определяется автоматически.

## Загрузка нескольких и любых похожих отчётов

- В кнопку загрузки можно выбрать **сразу несколько файлов .xlsx**.
- Кроме двух известных шаблонов подходят **любые похожие отчёты** (мониторинги, срезы, другие классы, предметы, четверти). Незнакомый файл приложение прочитает целиком, покажет данные и простую статистику, а полный анализ сделает ИИ.
- Если файлов несколько, появляется **«📚 Сводный анализ всех файлов»**: таблица сравнения, динамика білім сапасы по параллелям между четвертями и общий отчёт в Word и Excel (в Excel — лист «Жиынтық» и копии всех исходных таблиц).
- Можно открыть и любой файл по отдельности — для него будет свой анализ и свои Word/Excel.

**Что умеет:**
- загружает Excel-отчёт по шаблону «БЖБ және ТЖБ нәтижелерінің талдауы»;
- пересчитывает сапа % и үлгерім %, находит расхождения с таблицей и списками учеников;
- строит динамику каждого ученика (Т / О / Ж по всем работам) и выделяет группу риска;
- сравнивает подгруппы, показывает графики;
- делает полный анализ с советами учителю через Claude (Anthropic API) — на казахском языке;
- сохраняет отчёт в **Word (.docx)** и **Excel (.xlsx)**. В Excel заполняются пустые разделы 2–4 исходного шаблона (қиындықтар, себептері, жоспарланған жұмыс) и добавляются листы с проверкой, динамикой учеников и анализом.

## Анализ ИИ без API-ключа (через ChatGPT)

На вкладке «🤖 ЖИ талдауы» выберите «ChatGPT — бесплатно, без ключа»:
1. приложение само соберёт промпт со всеми данными и расчётами — скопируйте его;
2. откройте chatgpt.com (подойдёт бесплатный аккаунт, а также Gemini, DeepSeek, Claude.ai), вставьте и отправьте;
3. скопируйте ответ кнопкой «Копировать» и вставьте обратно в приложение;
4. скачайте Word и Excel — ответ ИИ будет в отчёте.

Режим «Claude API» делает то же автоматически, но нужен платный ключ Anthropic.

## Запуск на своём компьютере

```bash
pip install -r requirements.txt
streamlit run app.py
```

Откроется страница http://localhost:8501.

## Публикация как веб-страницы (бесплатно)

1. Создайте репозиторий на GitHub и загрузите туда все файлы этой папки
   (`app.py`, `requirements.txt`, `README.md`, `.gitignore`, папку `.streamlit`).
2. Зайдите на [share.streamlit.io](https://share.streamlit.io), войдите через GitHub.
3. **Create app** → выберите репозиторий, ветку `main`, файл `app.py` → **Deploy**.
4. Чтобы ключ ИИ не вводить каждый раз: **App settings → Secrets** и вставьте
   ```toml
   ANTHROPIC_API_KEY = "sk-ant-..."
   ```
   Ключ создаётся на [console.anthropic.com](https://console.anthropic.com).

⚠️ Никогда не загружайте файл `.streamlit/secrets.toml` с ключом на GitHub — он уже добавлен в `.gitignore`.

## Формат входного файла

- строки результатов вида `БЖБ 1 (1 топ)`, `ТЖБ (2 топ)`;
- столбцы: Оқушы, Максималды ұпай, төмен / орташа / жоғары, Сапа %, Үлгерім %;
- блок «1. … білім деңгейін көрсетті» со списками учеников по уровням (через запятую);
- заголовки разделов 2, 3, 4 — программа запишет текст в строку под каждым.

Программа ищет данные по подписям, а не по номерам ячеек, поэтому небольшие сдвиги строк не мешают.

## Формула сапа %

В разных школах сапа % считают по-разному, поэтому в боковой панели можно выбрать:
- `Ж / барлығы × 100` — доля учеников высокого уровня;
- `(О + Ж) / барлығы × 100` — средний и высокий уровень.

Если в вашей школе сапа считается по баллам (например, доля учеников с результатом от 65%),
то по одним уровням Т/О/Ж её точно не вычислить — программа покажет расхождение, и его стоит перепроверить вручную.
